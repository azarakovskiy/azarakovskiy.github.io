Platform migration

API gateway

API gateway and authentication service migrated from the platform's live PHP monolith.

My ownership

I helped form the team that later grew to four engineers. I co-architected the gateway, authentication service and authorization framework in Go, and ensured a staged migration.

We built the gateway on Zalando Skipper and used DynamoDB for the high-throughput authentication service. Custom Kubernetes CRDs and Helm-based registration let service teams publish routes automatically, while a Go authorization library let them define and test their own rules.

Result

We ran the old and new systems side by side for about six to twelve months, then removed routing and authentication code from the PHP monolith. The gateway handled more than 10,000 requests per second, and all seven cross-functional teams adopted the authorization library.

I contributed Kubernetes label-selector filtering upstream to Zalando Skipper.
